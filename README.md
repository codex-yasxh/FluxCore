# FluxCore

A multi-tenant event-ingest and webhook-delivery platform.

## Objectives

- Reliable event ingestion
- Tenant isolation
- Idempotent event processing
- Durable webhook delivery
- Retry and dead-letter handling
- Rate limiting
- Observability
- Production deployment

## Technology

- Python
- FastAPI
- Pydantic
- PostgreSQL
- SQLAlchemy
- Redis
- Celery
- Docker

## Status

Under active development.
